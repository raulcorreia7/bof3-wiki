The game's own code and data are the evidence for every layout and name in this wiki. The external research listed here confirms a fact or gives a lead, and it never replaces a check of the game's bytes. The tables give each source with its terms, what the wiki took from it and the pages it supports. Pages cite and summarize these sources and copy none of their text or tables.

"Terms" is what the owner states. "None stated" means the page or repository carries no license, so all rights stay with the owner and the source is cited only. A "snapshot" is an [archive.org](https://web.archive.org/) copy of the page when one exists.

## How a fact cites its source

- A layout or name proven by the game's data cites a function as `Name (image@0xADDR)` ([conventions](../../concepts/notation/#images-and-citations)). An external source, if any, confirms it.
- A page that rests on a community source names it in the `Evidence` bullet of its "Sources and confidence" section and links this page.
- A fact that only a community source states is a lead, tagged `[inferred]` ([conventions](../../concepts/notation/#evidence-tags)), until a read of the game's own code or data confirms it.
