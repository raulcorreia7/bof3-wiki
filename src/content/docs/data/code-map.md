The game's code is 428 images: the resident executable, the logo program and 426 EMI overlays. This page maps each image family, each address range of the executable and of the resident game layer, and each asset class to the job it does and the functions that do it. The pages that own each mechanism are linked from Related, and roles that no reader or caller establishes are listed as not identified.

## Terms

Names are labels from this research. An address name such as `func_80158F80` means the function has no readable name, and a range with no entry points is listed by address only. `slus` is the main executable `exe/slus_004_22`. A citation reads `Name (image@0xADDR)`, and an address is meaningful only inside its image, because overlays share addresses. A role that no reader or caller establishes is called not identified.

## Memory map

The RAM map is in [Memory](../../concepts/memory/), and the load address of each image family is in [Programs and load addresses](../programs/#load-addresses). Overlays at one address replace one another. `slus` and the EMI overlays share RAM, so an overlay calls `slus` and `game/00` by address and neither calls back by name. The slot windows are reserved regions of the `slus` image. The `boss`, `area030/05` and `area049/13` images load at the addresses of the windows, so they occupy them.

### Members that differ

`boss/*`. 12 images add a name to the common four: `Boss_FinishDefeat` (`boss002`, `004`, `017`,
`022`; it banks the enemy's EXP and Zenny and sets the victory bit on the last enemy),
`Boss_EndEntrance` (`boss022`), `Boss_InitEnemy` (`boss037`, `040`, `042`, `049`), `Boss_RunSubStep`
(`boss036`, `052`), `Effect_ShakeScreen` (`boss033`) and `Area_RoundSpriteCoordinate` (`boss055`).
`boss002`, `004`, `008` and `014` carry numbered variants of the hook names (`Boss_EndBattle2` and
so on). `boss055` is the largest (60 functions). What each boss does beyond the hooks is not identified.

`bmagic/*`. 20 images name `BMagic_RunStep`; the others name `Effect_PlayOnce` (`magic008`,
`015`, `020`, `145`, `146`), `Effect_CountDownTimer` (`magic006`, `009`, `039`, `040`, `059`, `126`,
`145`) or `Effect_NextStep` (`magic062`, `082`). The effect each module draws is not identified.

`plchar/*`. 7 images (`plp012`, `015`, `016`, `025`, `026`, `034`, `056`) define the turn shape:
`Char_AdvanceScript (emi/plchar/plp012/00@0x801CEC30)`, `Char_SpawnActor (emi/plchar/plp012/00@0x801CEF14)` (claims a field record from
`g_ActorSlots`), `Char_StartTurn`, and `Char_ProbeFacingCell`. 11 images
(`plp247`, `257`, `267`, `278`, `27a`, `457`, `467`, `478`, `567`, `578`, `678`) define the walk
shape: `Char_WalkStep (emi/plchar/plp478/00@0x801CE898)` ("runs one field-character route step").
`plp349` has no readable name. Which character each module drives is not identified.

`world0N/*`. 38 to 48 areas per world load at `0x801F2C00`. Provable differences:
`world00/area030/04` loads at `0x801D0C00` (237 functions; it calls
`Area_DrawScene (exe/slus_004_22@0x8014BA54)` each frame), `world00/area030/05` loads at `0x800F5000` and
`world01/area049/13` at `0x80117000`. 19 areas hold no functions (for example
`world00/area006/13`, `world03/area122/13`). The common names are `Area_Update (emi/world01/area065/13@0x801F35F0)` ("the
area frame update"), `Area_RunEvent`/`Message_OpenAnswerMenu` (entry `0x801F2C04`),
`Actor_AdvanceWhenPartyNear`, `Actor_SlideScreenX`, `Area_ClearWorkColumn`. `world04` has the most
named functions (85). Area script content is not identified.

## Shared function bodies

Several images carry one function body. Equal function sizes in the overlays mean one shared body. Sizes diverge where a variant exists (`Menu_DrawPortrait` is 384 bytes in
`sisyou`, 332 elsewhere). The scratchpad cell `g_SpadWork` (`0x1F800044`) points at an actor row; the
actor record is in [field](../field/#actor-rows).

## Open questions

- `battle/batl_end`, `batl_ovr`, `batl_re2/01`, `etc/bate/03`, `scenario/sce15ef0-3` and the 21 images with no functions have no identified role.
- Address-named blocks have no identified role: the 22 script predicates, the 21 local-mode callbacks and most of the 681 functions in `game/00`.
- Script opcodes for `scenario` and `world*`.

## Sources and confidence

- **Confidence:** medium. The family, range and asset-class roles are read from the names, callers and call counts of the images, but many ranges are address-named and have no identified role.
- **Evidence:** the function names and address ranges of all 428 images, the callees and call-site counts of each unnamed range, the handler tables that name callees of `jalr` calls, and the load, parse and use functions of each asset class.
